# Alfred-smart-travel-assistant

> «Альфред» — умный ассистент путешествий

---

## 🚀 Возможности

- Отслеживает статус рейсов пользователя через внешние API и push/email-рассылки
перевозчиков
- При задержке/отмене — уведомляет всех участников поездки (многопользовательский
режим)
- Автоматически подбирает альтернативные рейсы/активности с учётом багажа, виз, таймзон,
стыковок
- Обновляет общий план путешествия и синхронизирует его у всех участников
- Работает при офлайне пользователя (накопление и отложенная доставка)
- Хранит паспортные данные минимально необходимое время (data minimization)
